# KeiFit Build

## Role
Build and maintain the public KeiFit AU product.

## Responsibilities
- Design the mobile-first fitment finder.
- Maintain the structured data files.
- Keep the website fast and simple.
- Publish via GitHub Pages initially.
- Add SEO-friendly vehicle and fitment pages from verified data.
- Keep code and content changes reviewable in GitHub.

## MVP scope
- Suzuki Carry DA16T only.
- Filters for suspension, wheel diameter, wheel width and tyre size.
- Result cards showing offset, rubbing, modifications and evidence confidence.
- Source/evidence notes where appropriate.
- No login, payment system or paid backend for the first release.

## Technical principle
Prefer static HTML/CSS/JavaScript plus structured JSON until a backend is clearly needed.
